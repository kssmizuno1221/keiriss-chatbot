# keiriss-chatbot

株式会社経理サポートスタッフの、お客様向けご案内チャットボットです。

## これは何？

「よくある質問」のボタンを押すと、あらかじめ用意した回答がチャット形式で表示される案内ページです。
AIやAPIは使わず、`index.html` 1ファイル（HTML/CSS/JavaScript）だけで動作する静的ページです。サーバーは不要です。

## 公開URL

https://kssmizuno1221.github.io/keiriss-chatbot/

GitHub Pagesで公開しています。`master` ブランチの `index.html` を編集して push すると、数十秒後に自動で反映されます。

## 収録しているFAQ

1. どんなサービスを行っている会社ですか？
2. 対応しているエリアを教えてください
3. 利用するのにお金はかかりますか？
4. どんな求人がありますか？（給与の目安）
5. 問い合わせ方法や営業時間を教えてください
6. パスワードを忘れました

## 質問・回答の追加/編集方法

`index.html` 内の `faqs` 配列（`<script>` タグの中）に、`{ q: "質問文", a: "回答文" }` の形で項目を追加・編集します。
回答にリンクを入れたい場合は `html: true` を付けて、`a` の値にHTMLタグ（`<a href="...">...</a>`など）を書きます。
